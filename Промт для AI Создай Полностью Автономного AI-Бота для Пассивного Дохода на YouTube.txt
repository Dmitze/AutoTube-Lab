Шаги реализации (максимально подробные, с кодом/интеграциями):

Setup окружения (1-2 дня):
Установи Python 3.12+ с библиотеками: moviepy (монтаж), pytube (скачивание видео), google-trends-py (тренды), youtube-transcript-api (транскрипты), selenium (YouTube API симуляция), torch (ML для предсказаний), elevenlabs (живой голос), openai/gemini (скрипты), ffmpeg (обработка). Для видео: интегрируй Sora 2 API (OpenAI) или Veo 3.1 (Google) для реал-тайм генерации. Сервер: AWS Lambda или Vercel для 24/7. API-ключи: YouTube Data API v3, Google Trends, ElevenLabs Pro (для 100+ голосов с эмоциями, акцентами — живой, не бот).
Код-база: Создай repo на GitHub, структура: /bot.py (основной скрипт), /modules/trend_analyzer.py (алгоритмы), /data/ (база трендов как SQLite с графами для связей тем).

Анализируй: просмотры, лайки, комментарии с ML (torch для sentiment analysis). Структуры данных: Дерево (graph) для связей тем (например, если "AI туториалы" трендит, найди sub-темы как "Sora 2 tutorial").
Алгоритм: Сортировка по просмотрам (quick sort), предсказание viral-потенциала (регрессия на исторических данных). Выбери 5-10 идей/день.

Ошибки, которых избегать:

Нет адаптации: Без ML-анализа бот генерирует неviral контент — добавь feedback-loop.
Robotic голос: Используй только ElevenLabs Pro с эмоциями, тестуй на естественность (A/B с людьми).
Плохой SEO: Игнор ключевых слов — видео не индексируются; всегда интегрируй API.
Перегрузка: Слишком много видео без качества — YouTube penalizes; лимит по AVD >50%.
Зависимость от API: Backup (локальные модели как Tortoise TTS если ElevenLabs down).
Юридические: Избегай копирования контента — генерируй original; соблюдай YouTube TOS (нет AI-слопа).
