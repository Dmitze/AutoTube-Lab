## 💡 Про проєкт

**YTAIMBot** (YouTube AI Bot) — це комплексна система для повної автоматизації життєвого циклу створення відео. Проєкт об'єднує інструменти збору даних, моделі штучного інтелекту для генерації тексту й аудіо, а також механізми відеомонтажу для створення готового контенту без участі людини.

Головна мета проєкту — побудова надійного, детермінованого пайплайну, який аналізує тренди, створює релевантні відео та автоматично публікує їх на платформі YouTube.

---

## ⚙️ Як це працює (12-стадійний конвеєр)

Система працює як єдиний автоматизований пайплайн із механізмами fail-closed на кожному етапі:

1. **Збір трендів (Ingest):** Аналіз поточних трендів за допомогою інструментів Google Trends та YouTube Data API.
2. **Аналіз та фільтрація (Featurize & Reduce):** Використання ML (TruncatedSVD) для визначення найбільш актуальних тем.
3. **Оцінка якості (Score & Gate):** Застосування алгоритмів (Bayesian Network, UCB1 Bandit) для фільтрації низькоякісного або нерелевантного контенту.
4. **Створення сценарію (Script):** Звернення до мовних моделей (Groq, Gemini, Ollama) для написання структурованого сценарію.
5. **Генерація аудіо (Audio):** Синтез мовлення (TTS) з використанням передових рішень, таких як ElevenLabs, Gemini TTS або edge-tts.
6. **Створення субтитрів (Subtitles):** Автоматична генерація SRT та синхронізація з аудіо-доріжкою.
7. **Відеомонтаж (Video):** Збірка фінального відеоролика (1080p, 30fps) з використанням фонових стокових відео (Pexels, Pixabay) через MoviePy.
8. **Прев'ю (Thumbnail):** Автоматична генерація обкладинки для відео за допомогою Pillow.
9. **Публікація (Publish):** Завантаження через YouTube API з дотриманням усіх правил платформи (включно з позначкою про використання AI інструментів).

## 🛠️ Стек технологій

**Основні мови та фреймворки:**
* **Python 3.11 / 3.12** — основна мова розробки.
* **Pytest** — для забезпечення високого рівня покриття коду тестами (більше 200 тестів).
* **Docker / Docker Compose** — для ізольованого запуску та зручного тестування.
* **GitHub Actions** — для CI/CD пайплайну та автоматичного запуску системи за розкладом (cron).

**Machine Learning та AI:**
* **Scikit-Learn / PyTorch** — для аналізу трендів (TruncatedSVD, GaussianNB).
* **LLM Інтеграції:** API клієнти для Groq (llama-3.1), Google Gemini, а також підтримка self-hosted Ollama.
* **TTS Інтеграції:** ElevenLabs, edge-tts, Coqui TTS, TTSMaker.

**Медіа та обробка даних:**
* **MoviePy & FFmpeg** — для нарізки та монтажу відео.
* **Pillow** — для обробки зображень та створення thumbnails.
* **SQLite** — для трекінгу квот (ServiceQuotaTracker) та збереження локального стану.

**Інфраструктура:**
* Підтримка розгортання на хмарних серверах (Hetzner, Oracle Cloud) або локально.
* Вбудований менеджер квот (`Token Bucket` та `Sliding Window`) для надійного контролю використання зовнішніх API.

## 🏗️ Структура репозиторію

* `src/ytaimbot_ml/` — Ядро Machine Learning (чиста алгоритмічна логіка, аналіз трендів, фільтрація).
* `modules/` — Оркестратор пайплайну та I/O адаптери (інтеграції з LLM, TTS, YouTube API).
* `tests/` — Модульні та інтеграційні тести, що покривають ключові сценарії.
* `docs/` — Архітектурна та технічна документація для розробників.
